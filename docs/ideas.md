# シュールなバカゲー 企画案（5本）

条件: シュールな笑い / ブラウザで遊べる / 低コスト（静的HTML+JSのみ、サーバー不要、GitHub Pagesで無料公開可）

実装の軽さ: ★が少ないほど軽い（★1=1日、★3=数日）

---

## 案1. 課長を定時で帰らせる
- **一言**: 定時の17:30、課長がなかなか帰らない。あらゆる手で帰らせろ。
- **遊び方**: 画面は無表情な課長が座ったオフィス1枚絵。「照明を消す」「BGMを蛍の光にする」「課長の椅子を1cmずつ下げる」などの行動ボタンを押すと、課長が一言だけ反応する。正解の組み合わせで課長が静かに帰る。
- **笑いどころ**: 課長がどんな仕打ちにも「うん」しか言わない。椅子を下げ切ると床に座ったまま仕事を続ける。エンディングで課長が帰った後、部下も誰も帰らない。
- **実装の軽さ**: ★（ボタンと状態フラグとテキストだけ）

## 案2. 消しゴムのカスを育てる
- **一言**: 机に落ちた消しゴムのカスを、立派なカスに育てる育成ゲーム。
- **遊び方**: クリックで「こする」とカスが少しずつ大きく丸くなる。放置するとカスが勝手に自分語りを始める。一定サイズで「進化」するが、進化先はだいたいカスのまま。
- **笑いどころ**: 進化演出だけ異常に壮大（BGM・光・「おめでとう！カスは、カスに進化した！」）。カスの自分語りが妙に哲学的。
- **実装の軽さ**: ★（クリッカー系。数値とテキスト表示のみ）

## 案3. 正しい角度でお辞儀せよ
- **一言**: 相手に合わせて完璧な角度のお辞儀をするリズム＆タイミングゲーム。
- **遊び方**: 次々に現れる相手（取引先、社長、鳩、自販機）に対し、ボタン長押しで体を傾け、指示された角度で離す。「鳩 47度」など指示が理不尽。
- **笑いどころ**: 相手が鳩でも自販機でも審査が厳しい。誤差1度で「無礼者」判定。最終ボスは「鏡に映った自分」。
- **実装の軽さ**: ★★（Canvasで棒人間の回転＋判定）

## 案4. エレベーターの沈黙
- **一言**: 知らない人と2人きりのエレベーター。1階に着くまで気まずさに耐えろ。
- **遊び方**: 気まずさゲージが時間で上がる。「階数表示を見る」「スマホを見るふり」「咳払い」などでゲージを下げるが、同じ行動を連打すると相手が怪しむ。相手が突然話しかけてくるイベントに選択肢で答える。
- **笑いどころ**: 50階からのスタートなのに1階ずつしか進まない。相手の話しかけが「…鮭、好きですか」など脈絡ゼロ。途中で3人目に乗ってくるのが馬。
- **実装の軽さ**: ★★（ゲージ＋ランダムイベント＋選択肢）

## 案5. 何もしないゲーム
- **一言**: 何もしないことを極めるゲーム。マウスを動かしたら負け。
- **遊び方**: 画面には「何もしないでください」とだけ表示。操作しない時間がスコア。画面の中では勝手にどうでもいい出来事（おじさんが横切る、雲が謝る）が起きて誘惑してくる。
- **笑いどころ**: 誘惑イベントのどうでもよさ。長く我慢するほどイベントが壮大になるのに、触ったら即終了で「あなたは何かをしてしまいました」。
- **実装の軽さ**: ★（入力検知＋タイマー＋イベント表示）
