# 企画書（ドラフト）: 何もしないゲーム

> Claude Code への実装依頼用の仕様書。ユーザーの最終決定待ちの下書き。

## 1. コンセプト
- 画面には「何もしないでください」とだけ表示される。**操作しなかった時間がスコア。**
- 画面の中では、どうでもいい出来事が次々に起きてプレイヤーを誘惑する。触ったら即終了。
- 笑いの軸: 誘惑のどうでもよさ／真顔で進むナレーション／終了時の冷たい一言。

## 2. プラットフォーム・技術条件
- ブラウザで動く静的サイト（HTML / CSS / バニラJS）。ビルド不要、外部ライブラリなし。
- 公開先: GitHub Pages（無料）。
- 対応: PCとスマホの両方（縦画面優先のレスポンシブ）。
- 画像素材は使わず、絵文字・CSS・テキストで表現する（素材コストゼロ）。
- 音はなしで成立させる。効果音はWeb Audio APIの簡単なビープ程度まで（任意）。

## 3. 画面構成
1. **タイトル画面**: 「何もしないゲーム」＋「はじめる」ボタンのみ。ベスト記録を表示。
2. **プレイ画面**: 中央に「何もしないでください」。右上に経過時間（秒、小数1桁）。背景で誘惑イベントが発生。
3. **結果画面**: 「あなたは何かをしてしまいました」＋記録＋称号＋何をしたか（例:「マウスを 3px 動かしました」）＋「もう一度」「Xで共有」ボタン。

## 4. ルール（負け判定）
プレイ開始から1.5秒の猶予の後、以下のいずれかを検知したらゲームオーバー。
- `mousemove` / `mousedown` / `wheel` / `keydown`
- `touchstart` / `touchmove`
- ウィンドウのフォーカス喪失・タブ非表示（`visibilitychange`, `blur`）→ 結果文言は「よそ見をしました」
- （任意）スマホの傾き `devicemotion` の閾値超え → 「スマホを揺らしました」

結果画面では「何をしてしまったか」を具体的に表示する（移動距離、押したキー名など）。

## 5. 誘惑イベント
- 経過時間に応じて段階的に派手になる。イベントは画面上を横切る／出現して消える、テキスト＋絵文字の演出。
- データは `events.js` の配列で管理し、追加しやすくする（`{ minTime, text, emoji, animation }`）。

| 経過時間 | イベント例 |
|---|---|
| 5秒〜 | おじさん🧍が画面を横切る／「ここを押すと何か起きます」ボタンが出る（押すと負け） |
| 15秒〜 | 雲☁️が「さっきはすみませんでした」と謝る／ハエ🪰が画面に止まる |
| 30秒〜 | 「本当に何もしないんですか？」と画面が話しかけてくる／偽の「閉じる×」ボタン |
| 60秒〜 | 小さな祭り🏮が始まる／おじさんが戻ってきて会釈する |
| 120秒〜 | 宇宙から「何かしてください」と通信が届く／画面が「かまって」と少し揺れる |
| 300秒〜 | エンドロールが勝手に流れ始める（まだゲームは続いている） |

ルール: 誘惑ボタンを押す＝負け（これが一番の罠）。

## 7. 保存・共有
- ベスト記録は `localStorage` に保存（読み書きは try/catch で囲む）。
- 共有: X（旧Twitter）の投稿画面を URL で開くだけ（API不要）。文面例: 「何もしないゲームで 42.3秒 何もしませんでした。称号: 地蔵 #何もしないゲーム」

## 9. 完成条件
- PCとスマホで、開始→放置→操作で終了→結果表示→再挑戦が動く。
- 5秒・15秒・30秒・60秒の各段階でイベントが出る。
- ベスト記録がリロード後も残る。
- GitHub Pagesで公開できる状態。
