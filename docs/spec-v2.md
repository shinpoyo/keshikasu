# 企画書: 消しゴムのカスを育てる（v2）

> Claude Code への実装依頼用の仕様書です。このファイルを渡して「この仕様で実装して」と頼めば作れる細かさで書いています。
> v2 の変更点: クリッカー要素で長く育てられるようにした／進化先を約40種類に増やした／子どもをメインターゲットにした。

---

## 1. コンセプト
- 机に落ちた**消しゴムのカス**を、こすって、まぜて、育てるクリッカー＆放置育成ゲーム。
- **メインターゲット: 小学生（6〜12歳）**。大人が見てもクスッとする、やさしいシュールさ。
- 笑いの軸
  1. **進化の演出だけ異常に壮大**。でも、進化してもだいたいカス。
  2. カスが**ちょっと不思議なひとりごと**を言う（こわくない、いじわるじゃない）。
  3. 手伝ってくれる仲間が、だんだん**スケールがおかしくなる**（アリ → おじいちゃん → 月）。
- 遊ぶ時間の目安: 最初の進化まで30秒、1周（消しゴムに戻るまで）1〜2時間、図鑑コンプリートまで数日〜数週間。

## 2. プラットフォーム・技術条件
- ブラウザで動く静的サイト（HTML / CSS / バニラJS）。ビルド不要、外部ライブラリなし。
- 公開先: GitHub Pages（無料）。
- 対応: スマホ・タブレット・PC（縦画面優先のレスポンシブ）。タブレットで遊ぶ子どもを重視。
- 画像素材は使わない。カスは CSS（不規則な角丸の塊＋色・模様）で描き、種類ごとに見た目を変える。
- 効果音・ジングルは Web Audio API で合成（ファイル不要）。音はオン初期値、設定でオフにできる。

## 3. 子ども向けのルール（必須）
- **ことば**: ひらがな・カタカナ中心。漢字は小学2年生までの漢字に限る。1回の文は短く（20文字前後）。
- **ボタン**: 大きく（タップ領域 最低48px）、アイコン＋ひらがなのラベル。
- **数字**: 大きい数は「1.2まん」「3.4おく」「5ちょう」のように日本語の単位で表示。
- **安全**: 広告・課金・外部リンク・SNS投稿ボタン・ログイン・チャットはすべてなし。個人情報の入力なし（カスの名前だけ、端末内にのみ保存）。
- **こわくない**: 失敗・死亡・ゲームオーバーはない。カスは何があっても消えない（吹いても戻ってくる）。
- **遊びすぎ防止**: 連続30分プレイすると、カスが「そろそろ ひとやすみ しよう」と言って寝る演出（遊び続けることはできる）。
- **保護者向け**: タイトル画面に小さく「このゲームについて（おうちのかたへ）」を置き、データは端末内だけに保存されること、課金・広告がないことを書く。

## 4. 画面構成
- **メイン画面（1画面）**
  - 中央: 木目の机の上にカス。こするたびにぷるっと揺れて、細かいカスが飛び散る。
  - 上部: カスの名前・しゅるい名・おもさ（mg）・ケシポイント（所持数と1秒あたり）。
  - 中段: カスのひとりごと吹き出し。
  - 下部タブ: 「どうぐ」「なかま」「まぜる」「ずかん」の4つ。
- **おうちのかたへ／せってい**: 音のオンオフ、データのリセット（2回確認）。

## 5. リソースとパラメータ
| 名前 | 表示名 | 意味 |
|---|---|---|
| `kp` | ケシポイント | お金にあたる。こする・なかまで増え、どうぐやなかまを買うのに使う |
| `mass` | おもさ（mg） | カスの育ち具合。**これまでに稼いだ kp の合計**から計算。使っても減らない |
| `stage` | だんかい | 進化の段階（1〜5）。`mass` の閾値で上がる |
| `trait` | けいとう | 何をまぜたかで決まる性質（黒・カラフルなど） |
| `mood` | きもち | ほめる・吹く・放置でかわる隠しパラメータ。特別な進化に使う |
| `shards` | けしゴムのかけら | 転生（6章）で手に入る永続ボーナス |

## 6. クリッカー要素
### 6-1. こする（タップ）
- 1タップで `kp` が「こする力」ぶん増える。連打OK。
- 10回に1回くらい「ごりっ」と大きく取れる（2倍、効果音つき）。

### 6-2. どうぐ（こする力を上げる）
値段は買うたびに1.15倍。

| どうぐ | こする力 | 最初の値段 | ひとこと |
|---|---|---|---|
| ゆび | +1 | 最初から | 「ゆびです」 |
| えんぴつの おしり | +3 | 15 | 「けしゴムが ついてない ほう」 |
| おおきな けしゴム | +10 | 200 | 「ふでばこに はいらない」 |
| でんどう けしゴム | +50 | 3,000 | 「ぶいーん」 |
| けしゴム こうじょう | +300 | 50,000 | 「なにかを けしつづけている」 |
| ロードローラー | +2,000 | 100まん | 「なぜか ある」 |

### 6-3. なかま（放置で自動にふえる）
値段は買うたびに1.15倍。

| なかま | 1秒あたり | 最初の値段 | ひとこと |
|---|---|---|---|
| アリさん | 0.2 | 10 | 「カスを はこんで きてくれる」 |
| ハムスター | 1 | 100 | 「まわしゃ しゃかしゃか」 |
| しらない おじいちゃん | 8 | 1,200 | 「むかしは もっと カスが あった」 |
| けしゴムぶの ぶいん | 50 | 15,000 | 「ぶかつです」 |
| つき | 400 | 20まん | 「いんりょくで あつめてくれる」 |
| うちゅうの いし | 3,000 | 300まん | 「……」 |

- 「なかま」を買うと、机のまわりにそのキャラが小さく出てくる（絵文字で表現: 🐜🐹👴🧑‍🎓🌙🌌）。

### 6-4. ほめる／ふーっと吹く
- **ほめる**（10秒に1回）: 30秒間 `kp` が1.5倍。カスが照れる。`mood` の「じしん」が上がる。
- **ふーっと吹く**: カスが画面の外へ飛んでいき、3秒後に「ただいま」と戻ってくる。`kp` は減らない（子ども向けに罰なし）。`mood` の「たび」が上がる。ボーナスなしのただのボタン。
- **放置**: 20秒操作がないと、ひとりごとが始まる。`mood` の「しずか」が上がる。

### 6-5. オフライン進行
- ページを閉じていた間も、なかまが働いた分の `kp` が入る（最大8時間ぶん）。
- 再訪時にカスが「きみが いないあいだ、〇〇について かんがえてた」と言う。

## 7. 進化（たくさんの種類）
### 7-1. だんかい（おもさで上がる）
| stage | おもさの目安 | だんかい名 |
|---|---|---|
| 1 | 0mg〜 | こつぶ |
| 2 | 1mg〜 | ふつうの |
| 3 | 50mg〜 | まとまった |
| 4 | 5,000mg〜 | りっぱな |
| 5 | 50まんmg〜 | でんせつの |

- `mass` は稼いだ `kp` の合計 × 0.01mg を目安にし、最初の進化（1mg）が約30秒で起きるように調整する。

### 7-2. けいとう（まぜたもので決まる）
「まぜる」タブで、`kp` を使って材料を1つまぜる。次の進化のときに、いちばん多くまぜた材料で `trait` が決まる。材料は `stage` が上がると増える。

| 材料 | けいとう | 見た目 | 解放 |
|---|---|---|---|
| なにもまぜない | ノーマル | はいいろ | 最初から |
| えんぴつの こな | くろ | まっくろ | stage 2 |
| いろえんぴつ | カラフル | にじいろのまだら | stage 2 |
| のり | ねばねば | テカテカ、のびる | stage 3 |
| ほこり | もふもふ | ふわふわの毛 | stage 3 |
| すなけし | ざらざら | つぶつぶ | stage 4 |
| きんの こな | キラキラ | 金色に光る | stage 4（値段がとても高い） |

- 種類名は「だんかい名＋けいとう名＋カス」。例: 「まとまった ねばねばカス」「でんせつの キラキラカス」。
- 7けいとう × 5だんかい = **35種類**。

### 7-3. とくべつな進化（隠し）
進化のときに `mood` が条件を満たすと、ふつうの種類のかわりに特別な種類になる。

| 条件 | 種類名 | ひとこと |
|---|---|---|
| ほめた回数が多い | じしょう カスのおうさま | 「わたしが カスの ちょうてんです」 |
| 吹いた回数が多い | たびするカス | 「いろんな つくえを みてきた」 |
| 放置時間が長い | さとったカス | 「なにも けさなくて いいんだよ」 |
| 1秒に10回以上こすった | あつあつカス | 「まさつで あったかい」 |
| 夜0時〜5時に進化 | よふかしカス | 「ねなさい」 |

- 合計 **40種類**。図鑑に「？？？」として枠だけ見せ、集めたくなるようにする。
- 種類・条件の定義は `data/species.js` に分け、あとから追加しやすくする。

### 7-4. 進化の演出
- 画面が暗くなる → 光 → 壮大なジングル → 大きな文字「おめでとう！」→ 結果発表。
- 結果の文は「カスは、〇〇カスに しんかした！」。**見た目はほぼ前と同じ**（色や模様が少し変わる程度）なのが笑いどころ。
- 演出は約3秒。初めての種類のときは図鑑に「あたらしい カス！」と追加される。

## 8. 転生（消しゴムにもどる）
- stage 5 になると「けしゴムに もどる」ボタンが出る。
- 押すと、カスが集まって**消しゴムになる**大演出 → ナレーション「けしゴムは、また なにかを けすでしょう」→ 新しいカスが1個ぽとりと落ちて、最初から。
- 引きつぐもの: 図鑑、`shards`（けしゴムのかけら）、周回数。
- リセットされるもの: `kp`、`mass`、どうぐ、なかま、まぜたもの。
- `shards` は転生時のおもさに応じて手に入り、1個につき全体の `kp` が +10%（永続）。
- 周回を重ねると、最初から使える材料が増える（2周目: えんぴつのこなが最初から、など）。

## 9. ひとりごと（例。`data/monologues.js` に配列で定義）
- ふつう: 「ぼくは なにかを けした けっか なんだ」「つくえの はしっこが せかいの はしだと おもってた」「まとまるって なんだろう」
- けいとう別: くろ「えんぴつの きもちが わかる」／キラキラ「まぶしくて ごめん」／もふもふ「ほこりじゃないよ。たぶん」
- なかま別: アリさん購入後「アリさんと ともだちに なった」／つき購入後「つきが ちかい」
- 各けいとうに最低5つ、合計50以上を用意する。

## 10. ずかん
- 40種類の枠を並べ、見つけた種類はカスの見た目・名前・ひとこと・見つけた日を表示。見つけていない種類は「？？？」とヒント1行（例:「いっぱい ほめると…？」）。
- 図鑑の達成数で称号がつく（10種類「カスはかせ みならい」、20種類「カスはかせ」、40種類「カスの かみさま」）。

## 11. 保存
- 状態はすべて `localStorage` に自動保存（10秒ごと＋ページを閉じる時）。読み書きは try/catch で囲み、保存できない環境でも遊べるようにする。
- データの形にバージョン番号をつけ、将来のデータ変更に備える。

## 12. ファイル構成（想定）


## 13. バランスの目安
- 最初の進化（stage 2）: 約30秒
- stage 3: 約5分／stage 4: 約30分／stage 5: 約1〜2時間
- 2周目以降は `shards` のおかげで少しずつ早くなる。
- 数値は `data/` に集めて、あとから調整しやすくする。

## 14. 完成条件
- スマホ・タブレット・PCで、こする・どうぐ・なかま・まぜる・ほめる・吹く・放置が動く。
- 35種類のふつうの進化と5種類の特別な進化が、条件どおりに起きて図鑑に登録される。
- 転生して2周目が始められ、図鑑とかけらが引きつがれる。
- リロード・再訪後も状態が残り、オフライン中の分が入る。
- 子ども向けのルール（3章）をすべて満たす。
- GitHub Pages で公開できる状態。

## 15. やらないこと
- サーバー、ログイン、ランキング、課金、広告、外部リンク、SNS投稿、画像素材、外部ライブラリ。
