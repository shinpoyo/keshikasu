> Claude Code への実装依頼用の仕様書です。このファイルを渡して「この仕様で実装して」と頼めば作れる細かさで書いています。
>
> v3 の変更点
> - **クッキークリッカー（Cookie Clicker）を土台に**、施設・アップグレード・ゴールデン・ニュース・実績・転生の仕組みを取り入れた。
> - 数字は **K / M / B / T** 表記（日本語の「まん・おく」は使わない）。**日本語と英語の切り替え**に対応。

## 1. コンセプト
- 机に落ちた**消しゴムのカス**をこすって「つぶ」を集め、カスを育てるクリッカーゲーム。
- 手本は**クッキークリッカー**。数字がどんどん大きくなる気持ちよさ、施設を買い足す楽しさ、転生でまた強くなる周回を、そのまま受け継ぐ。
- 独自の要素は**カスの進化**。集めたつぶの量と、まぜた材料で、カスが56種類に進化する。でも進化の演出だけ異常に壮大で、見た目はほぼカスのまま。
- **メインターゲット: 小学生（6〜12歳）**。大人や海外の人が見てもクスッとする、やさしいシュールさ。
- 遊ぶ時間の目安: 最初の進化まで30秒、最初の転生まで数時間、図鑑コンプリートまで数週間。

## 2. プラットフォーム・技術条件
- ブラウザで動く静的サイト（HTML / CSS / バニラJS）。ビルド不要、ゲーム用の外部ライブラリなし。
- 公開先: GitHub Pages（無料）。
- 対応: PC・タブレット・スマホ（13章のレイアウト参照）。
- 絵は**インラインSVGとCSS**で描く（画像ファイルなし）。フォントだけ Google Fonts から読み込む。
- 効果音・ジングルは Web Audio API で合成（音声ファイルなし）。

## 3. 言語と数字
### 3-1. 言語
- **日本語（初期値）と英語**を切り替えられる。ブラウザの言語が日本語以外なら英語で始める。
- 画面の文字はすべて `data/i18n/ja.js` と `data/i18n/en.js` に分け、コードに直接書かない。
- 日本語はひらがな・カタカナ中心で、漢字は少なめ（小学校低学年で読める程度）。英語はやさしい単語で書く。
- ゲーム内の名前: 日本語「けしカス」／英語 "Eraser Crumb Clicker"（2026-10-02 決定。他の言語は各言語の名前＋Clicker）。

### 3-2. 数字の表記（言語に関係なく共通）
| 範囲 | 表示例 |
|---|---|
| 1,000,000 未満 | `123,456`（3桁区切り） |
| 以上 | `1.234M` / `56.78B` / `9.1T`（有効数字4桁） |
| 単位の並び | K, M, B, T, Qa, Qi, Sx, Sp, Oc, No, Dc（それより上は `1.23e36`） |
- 設定で「科学的表記（1.23e9）」にも切り替えられる。
- 1秒あたりは `12.3M /s`、日本語でも「つぶ/びょう」ではなく `/s` に統一。

## 4. 子ども向けのルール（必須）
- **ボタン**: タップ領域は最低48px。アイコン＋短い文字。
- **安全**: 広告・課金・外部リンク・SNS投稿ボタン・ログイン・チャットはすべてなし。個人情報の入力なし（カスの名前だけ、端末内にのみ保存）。
- **こわくない**: 失敗・ゲームオーバーはない。カスは何があっても消えない。
- **遊びすぎ防止**: 連続30分プレイすると、カスが「そろそろ ひとやすみ しよう」と言って寝る演出（遊び続けることはできる）。
- **保護者向け**: 設定内に「おうちのかたへ / For parents」を置き、データは端末内だけに保存されること、課金・広告がないことを書く。

## 6. クリッカーの仕組み（クッキークリッカー準拠）
### 6-1. こする（クリック）
- 大きなカスをタップすると `crumbs` が増える。押した位置に `+12` のような数字がふわっと浮かび、つぶが飛び散る。
- こする力はアップグレードで上がる（6-3）。

### 6-2. 施設（なかま）
- 値段は `基本値段 × 1.15^持っている数`。まとめ買い（1 / 10 / 100）と売却（買値の25%）ができる。
- 持っている施設は、画面中央の「つくえ」エリアに**1行ずつ並んで見える**（クッキークリッカーの建物の列と同じ考え方）。

| # | ja | en | 基本値段 | 基本 /s | ひとこと |
|---|---|---|---|---|---|
| 1 | ゆび | Finger | 15 | 0.1 | 「じどうで こする ゆびです」 |
| 2 | アリさん | Ant | 100 | 1 | 「カスを はこんで くる」 |
| 3 | しらない おじいちゃん | Random Grandpa | 1,100 | 8 | 「むかしは もっと カスが あった」 |
| 4 | きょうしつ | Classroom | 12,000 | 47 | 「テストの あとは とくに とれる」 |
| 5 | けしゴムぶ | Eraser Club | 130,000 | 260 | 「ぶかつです」 |
| 6 | けしゴムこうじょう | Eraser Factory | 1.4M | 1,400 | 「なにかを けしつづけている」 |
| 7 | ロードローラー | Road Roller | 20M | 7,800 | 「なぜか ある」 |
| 8 | つき | The Moon | 330M | 44,000 | 「いんりょくで あつめてくれる」 |
| 9 | タイムマシン | Time Machine | 5.1B | 260,000 | 「きのうの カスを もってくる」 |
| 10 | パラレルつくえ | Parallel Desk | 75B | 1.6M | 「べつの せかいの つくえ」 |
| 11 | うちゅうの いし | Will of the Universe | 1T | 10M | 「……」 |
| 12 | もうひとりの カス | The Other Crumb | 14T | 65M | 「やあ」 |

- 値段と生産量のカーブはクッキークリッカーの建物に近づけている。数値は `data/buildings.js` にまとめ、あとから調整できるようにする。
- まだ買えない施設は、次の1つだけシルエット（「？？？」）で見せる。

### 6-3. アップグレード
- 条件を満たすと店の上段にアイコンが並び、1回だけ買える。
- **施設アップグレード**: 各施設を 1 / 5 / 25 / 50 / 100 / 150 / 200 個持つと解放。その施設の生産が2倍。
- **ゆびアップグレード**: こする力とゆびの生産が2倍（最初の3つ）、その後は「ゆび以外の施設1つにつき +0.1」系。
- **こする強化**: 「こすると /s の1%ぶん もらえる」を段階的に追加。
- **まぜる材料**（7-2）もアップグレードの一種として店に並ぶ。
- 各アップグレードに、短いシュールな説明文をつける（例:「えんぴつのおしりを みがいた。こする力 2ばい」）。

### 6-4. ゴールデンカス（ゴールデンクッキーにあたる）
- 2〜5分に1回、画面のどこかにキラキラ光る**ゴールデンカス**が数秒だけ現れる。押すと効果がランダムに1つ発動。

| 効果（ja / en） | 内容 |
|---|---|
| ラッキー / Lucky! | いまの /s の15分ぶん（ただし所持の15%まで）を即もらう |
| キラキラタイム / Sparkle Frenzy | 77秒間、/s が7倍 |
| ごりごりタイム / Scrub Frenzy | 13秒間、こする力が777倍 |

- 見のがしても罰はない。

### 6-5. カスニュース（ニュースティッカーにあたる）
- 画面上部に、シュールなニュースが1行ずつ流れる。**このゲームの笑いの中心のひとつ**。
- 進み具合に応じて内容が変わる（施設を買った数、進化の段階などで条件分け）。
  - 序盤:「つくえの うえで カスが みつかる。けいさつは『ふつうの カス』と はっぴょう」
  - アリさん購入後:「アリの ぎょうれつ、なぜか カスの ほうへ」
  - おじいちゃん購入後:「なぞの おじいちゃん、『むかしは よかった』と カスを こすりつづける」
  - つき購入後:「つき、すこし ちかくなる。しおの みちひきに えいきょう」
  - 終盤:「うちゅう、カスで できていた ことが はんめい」
- 各言語で最低80本。`data/news.js` に条件つきで定義する。

### 6-6. ほめる／ふーっと吹く／放置
- **ほめる**（10秒に1回）: 30秒間 /s が1.5倍。カスが照れる。
- **ふーっと吹く**: カスが画面の外へ飛んでいき、3秒後に戻ってくる。罰なし、ボーナスなし。
- **放置**: 20秒操作がないと、カスがひとりごとを言う。
- どれも `mood` に記録され、特別な進化（7-3）の条件になる。

### 6-7. オフライン進行
- 閉じていた間も、/s の10%ぶんのつぶが入る（最大8時間）。転生の永続アップグレードで割合を上げられる。

### 6-8. 実績
- 約100個。例: 「はじめての こする」「1M つぶ」「アリさん 100ぴき」「ゴールデンカスを 7こ」「3かい つづけて 吹いた」。
- 実績1つにつき /s +1%（クッキークリッカーのミルクを単純化）。
- 一部の実績は隠し（「？？？」表示）。

### 6-9. 統計
- これまでのつぶ、こすった回数、ゴールデンカスの数、プレイ時間、転生回数などを一覧表示。

## 7. 進化（このゲーム独自の要素）
### 7-1. だんかい（その周の totalCrumbs で上がる）
| stage | 必要な totalCrumbs | ja | en |
|---|---|---|---|
| 1 | 0 | にょろにょろの | Squiggly |
| 2 | 100 | ちらばった | Scattered |
| 3 | 10K | こんもりの | Heaped |
| 4 | 1M | まるまった | Rolled |
| 5 | 1B | かおが うかんだ | Face-Appeared |
| 6 | 1T | でんせつの | Legendary |
| 7 | 1Qa | うちゅうの | Cosmic |

### 7-2. けいとう（まぜた材料で決まる）
店の「まぜる」アップグレードで材料を買う。**最後に買った材料**が次の進化のけいとうになる（ずっと何もまぜなければノーマル）。

| 材料（ja / en） | けいとう | 見た目 | 解放 |
|---|---|---|---|
| なし | ノーマル / Plain | はいいろ | 最初から |
| えんぴつの こな / Pencil Dust | くろ / Graphite | まっくろ、少し光る | stage 2 |
| いろえんぴつ / Colored Pencil | カラフル / Rainbow | にじいろのまだら | stage 2 |
| のり / Glue | ねばねば / Sticky | テカテカ、のびる | stage 3 |
| ほこり / Dust Bunny | もふもふ / Fluffy | ふわふわの毛 | stage 3 |
| すなけし / Sand Eraser | ざらざら / Gritty | つぶつぶ | stage 4 |
| きんの こな / Gold Dust | キラキラ / Golden | 金色に光る | stage 5 |

- 種類名は「だんかい＋けいとう＋カス」（例: 「こんもりの ねばねばカス」/ "Heaped Sticky Crumb"）。
- 7だんかい × 7けいとう = **49種類**。

### 7-3. とくべつな進化（隠し、7種類）
進化の瞬間に条件を満たすと、ふつうの種類のかわりに特別な種類になる。

| 条件 | ja | en |
|---|---|---|
| ほめた回数が多い | じしょう カスのおうさま | Self-Proclaimed Crumb King |
| 吹いた回数が多い | たびする カス | Wandering Crumb |
| 放置時間が長い | さとった カス | Enlightened Crumb |
| 1秒に10回以上こすった | あつあつ カス | Toasty Crumb |
| 夜0時〜5時に進化 | よふかし カス | Night Owl Crumb |
| ゴールデンカスの効果中に進化 | ラッキー カス | Lucky Crumb |
| 転生10回以上 | なんども うまれかわった カス | Reborn Again Crumb |

- 合計 **56種類**。種類と条件は `data/species.js` に分ける。

### 7-4. 進化の演出
- 画面が暗くなる → 光の輪 → 壮大なジングル → 大きな文字「おめでとう！ / Congratulations!」→ 結果発表。
- 結果の文は「カスは、〇〇カスに しんかした！」。大げさな演出に対して、変化は「まとまった」「ころころした」程度なのが笑いどころ。ひとこと例: stage 5「かおが うかんだ。きのせいかも しれない。」
- 演出は約3秒。新しい種類なら図鑑に「NEW!」で登録。

## 8. 転生（けしゴムに もどる）
- クッキークリッカーの Ascend にあたる。いつでも実行できるが、`shards` が1以上もらえるときだけボタンが光る。
- もらえる `shards` = 全周の合計つぶ に対して `floor(cbrt(allTimeCrumbs / 1e12))` − すでにもらった数（クッキークリッカーと同じ考え方）。
- 演出: カスが集まって**消しゴムになる** → ナレーション「けしゴムは、また なにかを けすでしょう」→ 新しいカスが1個ぽとりと落ちて、最初から。
- 引きつぐもの: 図鑑、実績、`shards`、永続アップグレード、統計。
- リセットされるもの: つぶ、施設、アップグレード、だんかい。
- `shards` 1個につき /s +1%。加えて `shards` を使って**永続アップグレード**を買える（例: オフライン進行の割合アップ、ゴールデンカスが出やすくなる、最初から材料が使える）。

## 9. ひとりごと
- カスが吹き出しで話す。放置中・進化後・施設購入後・ゴールデンカスのときなど。
- 例: 「ぼくは なにかを けした けっか なんだ」「つくえの はしっこが せかいの はしだと おもってた」「まぶしくて ごめん（キラキラけいとう）」「つきが ちかい（つき購入後）」
- 各言語で最低60本。`data/monologues.js`。

## 10. ずかん
- 56種類の枠を並べ、見つけた種類はカスの絵・名前・ひとこと・見つけた日を表示。見つけていない種類はシルエットとヒント1行（例:「いっぱい ほめると…？」）。
- 達成数で称号（10種類「カスはかせ みならい」、30種類「カスはかせ」、56種類「カスの かみさま」）。

## 11. 保存
- すべて `localStorage` に自動保存（30秒ごと＋ページを閉じる時）。読み書きは try/catch で囲み、保存できない環境でも遊べるようにする。
- データにバージョン番号をつける。
- 設定から**セーブデータの書き出し・読み込み**（テキストのコピー＆ペースト。クッキークリッカーと同じ方式）。
- データのリセットは2回確認。

## 13. デザイン（きちんと作る）
### 13-1. 方向性
- テーマは「**ていねいに作られた文房具**」。紙・木目・鉛筆の線を感じる、あたたかくて上品な見た目。
- **ふざけた見た目にしない**。デザインはまじめで美しく、内容だけがシュール。このギャップが笑いを生む。
- 参考にする空気感: 良い文房具のパッケージ、絵本、クッキークリッカーの情報の密度と見やすさ。
- 子どもが遊ぶので、丸みがあって親しみやすいが、幼稚にはしない（大人が遊んでも恥ずかしくない）。

### 13-2. 色（CSS変数で定義）
| トークン | 用途 | 目安 |
|---|---|---|
| `--paper` | 背景 | 生成りの紙色 `#F6F1E7` |
| `--desk` | 机 | やわらかい木目 `#D9B98C` 系のグラデーション |
| `--ink` | 文字 | 墨色 `#2B2A28` |
| `--graphite` | 補助の文字・線 | `#6B6A66` |
| `--eraser-pink` | 主役の差し色（ボタン・強調） | 消しゴムのピンク `#F29CA3` |
| `--eraser-blue` | 2つめの差し色 | 消しゴムのスリーブの青 `#3E6FB0` |
| `--gold` | ゴールデンカス・レア | `#E7B533` |
- 文字と背景のコントラストは WCAG AA 以上。
- ダークモード（夜の机）もCSS変数の切り替えで用意する。

### 13-3. 文字
- 日本語: **M PLUS Rounded 1c** または **Zen Maru Gothic**（Google Fonts）。
- 英語・数字: **Nunito** など丸みのあるサンセリフ。数字は等幅数字（`font-variant-numeric: tabular-nums`）で、増えてもガタつかないようにする。
- つぶの数は画面でいちばん大きな文字にする。

### 13-4. 絵
- **カスはリアル寄りのイラスト**（写真ではなく、質感のあるイラスト）。**顔はつけない**。最初はただのにょろにょろした消しカス。
  - 色は鉛筆の黒がまじった濃いグレー。細かいけば立ち（繊維）、ざらついた質感、紙の上に落ちるやわらかい影をつける。
  - 形は だんかいで変わる: にょろにょろ1本 → ちらばった数本 → こんもりした山 → ころころの玉 → 玉に うっすら顔が うかぶ（stage 5 で初めて顔らしきものが出る。はっきりした顔ではなく、へこみや影の見間違いのような描き方）。
  - けいとう（7-2）は色・質感で表す（くろ=より黒く光る、カラフル=色鉛筆の粉がまじる、もふもふ=ほこりの毛、キラキラ=金粉 など）。
  - カスは机の上の**ノートの紙（うすい罫線）**の上に置く。紙は少しななめ。
  - 実装: SVG（フィルターで けば立ちと質感を出す）。1匹ずつ形が少し違うよう、シード値から生成する。
- UI（ボタン、枠、施設のキャラクター、アイコン）は、ていねいな文房具らしいフラットなイラストでよい。カスだけがリアル寄りで浮いて見えることも、笑いの一部にする。
- 絵文字は使わない。
- デザイン案: https://claude.ai/artifact/Bk1CgW2k5jTsoFFaUXVGR5

### 13-5. 動き
- こすったとき: カスがぷにっとつぶれて戻る（scaleの弾む動き、0.15秒）、つぶが飛び散る、`+N` が浮かんで消える。
- 数字の増加はなめらかにカウントアップ。
- 店: 買えるようになった瞬間にふわっと明るくなる。買ったときは小さく跳ねる。
- 進化・転生・ゴールデンカスの演出だけは、思い切り派手に（光、紙吹雪、画面全体）。
- `prefers-reduced-motion` のときは演出を控えめにする。

### 13-6. 進め方
1. **デザイン案（12-1 の画面一覧）を正とする**。まず各画面を静的に組んで見た目を合わせてから、ゲームの中身を実装する。カスの絵は `design/art/` のSVG（と生成スクリプト）を使う。
2. 色・余白・角丸・影はCSS変数にまとめ、画面ごとにばらばらにしない。

## 15. バランスの目安
