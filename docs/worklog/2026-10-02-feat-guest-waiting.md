# ゴールデンと普通の消しゴムを別の予定で出す・効果の重ねがけ（ブランチ `feat/guest-waiting`、2026-10-02）

## 流れ

- ユーザー:「3貯めるもやろう、効果は重複出来るね？」→ 見ていない間に来た分を3こまで右上の「待っている」欄にためる形を作った
- ユーザー:「好きなときに使うんではなくて、拾ってすぐ使うようにしたい、ゴールデンと2倍とかが合わさるとめっちゃ楽しそう」→ 欄をやめ、戻ったら順に浮かぶ形に
- ユーザー:「なんかイメージと違う」「ゴールデンと他の消しゴム出るテーブル別にすればそれぞれ出るとき、重なるときができる」→ ためる仕組みはやめて、出る予定を2つに分けた（この形で PR を出す）

## 変えたこと

- ふつうの消しゴム（かどけし・すなけし…）とゴールデン消しゴムは、べつべつの予定で来る。2こ同時に浮かぶこともあり、両方拾うと効果が重なる
  - ふつう: 1分半〜4分に1回（いままでどおり）。ゴールデンはまざらなくなった
  - ゴールデン: 5〜15分に1回（平均10分）。前は「ふつうの来る回の15%」で平均およそ19分に1回だったので、少し多くなる。ゴールデンのアップグレード（2倍・+10%・+15%）は間隔を短くする
  - ひきだしの「お客さんタイム」は両方の間隔を半分に。金のこなは ふつうの予定の回をゴールデンにする（いままでどおり）
  - 2こ同時のときは、左右の反対がわに出る
- 重ねがけ: 同じ種類の効果は、前は時間がリセットされていたので、残りに足すようにした（時間の効果は秒を足す、かどけし・ジャンボは回数を足す、ロケットはこまを足す）。ちがう種類は前からかけ算で重なる
- 画面: `#guest-gold` を追加。`K.guest.gold` / `goldAt` / `scheduleGold()`、`click(gold)`
- キャッシュ対策のバージョンを 0.39 に（main の PR #41 が 0.38）
- 確認: Playwright でスマホ・PC。2こ同時に浮かぶ、両方押すとキラキラタイムと すなけし（PCでは 香りつき）が同時にかかる、それぞれの予定が別に入りなおす、ゴールデンの間隔は平均10.0分。JS エラーなし

## 追記: 見ていない間は予定も止める

- ユーザー:「画面閉じてるときは消しゴム出ないようにしてね、そこは止める、ページを開いていて、図鑑とか見てる間は止めないということ」
- 前は ほかのタブ・画面を消している間も来る予定の時間が進み、もどった瞬間に来ていた。いまは その間は ふつう・ゴールデンの両方の予定を止める（もどったら残りの時間から続き）。眠っていた時間の上限(60秒)もなくした
- ずかん・みせなどを開いている間は止めない（いままでどおり上に浮かぶ）
- 確認: 予定の2秒前に3秒隠す → 来ない・残り2秒のまま、もどって2秒で2こ来る。ずかんを開いている間は来る。JS エラーなし
