# 2026-10-02 CrazyGames のプレビューで見つかった直し（fix/cg-preview）

## 依頼
- 「ずれてるじゃん　ふくとか」「設定アイコンが消えているし」「名前つけるの、転生時にもね」（CrazyGames の QA プレビュー画面の写真つき）

## 原因と直し
- **設定アイコンが消える**: 幅 1280px 以下で「メニューの文字をかくす」CSS が `span:last-child` だったため、アイコンしかない設定ボタンではアイコンが消えていた。`span[data-t]`（文字だけ）をかくすように変更。
- **「ふーっとふく」が折り返す**: CrazyGames では広告ボタン（2倍）が並んで3つになり、3つが同じ幅に分けられて長い文字が折り返していた。文字の長さに合わせて幅を分け、折り返さないように（`flex: 1 1 auto`・`white-space: nowrap`、すき間を少しつめた）。9言語・320〜1920px で確認。
- **消しゴムにもどる（転生）ときも名前をつける**: もどる演出のあとに名前の画面を出す。いまの名前を入れてあるので、そのままでもつけ直してもよい。「2こめの消しゴム」のように何こめかを出す。名前の画面の間は CrazyGames にゲームを止めたと伝える。
- 名前の画面の説明「このたんまつの中だけに保存」を、CrazyGames のセーブ（ログインすると別の端末でも同じ）に合わせて「セーブの中だけに保存、ほかの人には見えない」に。7言語も更新。
- 版 0.40。zip 作り直し。

## 確認
- Playwright: 1186x622（写真と同じ大きさ）で設定アイコンが出る、ボタンの文字がはみ出さない。ためしの SDK でもどる→名前→ゲームにもどる（gameplayStop/Start が呼ばれる）、ja/en/de で JS エラーなし。
- メモ: tools/i18n/check.py の「unknown text keys 1」は main にすでにあるもので、この直しとは関係ない。
