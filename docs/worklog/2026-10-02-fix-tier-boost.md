# どうぐ50こからの段階アップグレードに全体ボーナス（ブランチ `fix/tier-boost`、2026-10-02）

- ユーザー: 「頑張ってどうぐ100集めてアップグレードしてもあまり効率が上がらない」
- しらべたこと: 100こ集めやすいのは安いどうぐ（アリさん・友だち・おじいちゃん・漢字ドリル）で、終盤は全体の /s の 0.001% 未満しか出していない。段階アップグレードは「そのどうぐが2倍」だけなので、買っても全体はほぼ 0% しかふえなかった（26Qa ころのセーブで計算）
- なおしたこと: 50こ以上の段階アップグレードに「全体の /s も +○%」をつけた（50こ +3%、100こ +5%、150こ +7%、200こ以上 +10%。かけ算なので、書いてある % がそのままふえる）
  - 説明は「漢字ドリルが2倍働く。全体の /s も +5%。」
  - もう買ってあるぶんも効く（26Qa ころのセーブで /s が 約1.36倍）
- 英語の説明が変わったので、7言語のほんやく表（tools/i18n）に「全体の /s も +○%」を足して data/i18n を作りなおした（check.py で足りないもの 0）
- キャッシュ対策のバージョンを 0.38 に
- 確認: Playwright でスマホ。「伝説の漢字ドリル」（100こ）を買うと /s がちょうど 5% ふえる。JS エラーなし
