# 2026-10-05 feat/quality-v1 — CrazyGames 再申請に向けた品質アップ（版0.42）

CrazyGames から「ゲーム全体の品質がまだ基準に届かない」で不採用。ユーザーは「直して再申請」をえらんだので、審査で見られやすいところを直した。

## やったこと
- **開いたらすぐ遊べる**: タイトル画面と名前つけをはさまず、すぐゲーム画面へ（CrazyGames の「すぐ遊べること」）。
  - 名前はチュートリアルの「OK」のあとに聞く。カスの名前の下の「✎ 名前をつける」をタップしても つけられる（あとから変えることもできる）。
  - 新しいことば `nameIt`（9言語）。
- **こすったときの手ごたえ**:
  - 数字が大きく、ぽんっと出て ふわっと消える。白いふちどりで読みやすく。
  - れんぞくでこするほど数字が大きく、音（ポコッ）が少しずつ高くなる（`K.rt.combo`）。
  - とぶカスを 3〜5 → 5〜10 こに。消しゴムの先に けむり。つぶの数が ぴょこっと はねる。カスの ぷにっと感を強く。
- **次の目標**: カスの数の下に「次は ○○（あと ○）」とバーを出す。まだ買えない いちばん安いどうぐ・アップグレード。押すと みせのその場所が光る。新しいことば `goalNext`（9言語）。PC だけ。
- **PC の画面サイズ**:
  - 高さが 940px 以下（CrazyGames のふつうの窓 1186x668 など）では、ほめる・ふくボタンが下に見切れていた → カスの数を横ならびにし、つくえの大きさを高さに合わせて 1画面におさめた。
  - 1600x1000 以上（全画面など）では 文字・ボタン・つくえを大きく。
- PR #44（広告が出ないときは2倍ボタンをかくす）をこのブランチにも取りこみ、版を 0.42 に。

## たしかめたこと
- 新しく開く → すぐゲーム、チュートリアル OK → 名前画面 → ゲームにもどる。名前タップで変更できる。
- 転生のときの名前つけ（ja/en/de）、広告が出ないときの2倍ボタンかくし。
- 9言語 × 375x760 / 1186x668 / 1920x1080 で はみ出しなし・JS エラーなし。
- 1186x668, 1280x720, 1366x768, 1440x900, 1600x900, 1920x1000, 1920x1080, 2560x1440 で 左の列がスクロールしない。
