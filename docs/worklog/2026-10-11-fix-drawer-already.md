# 2026-10-11 fix/drawer-already — しまってある材料に「しまう」ボタンを出さない（版0.45）

ユーザー「すでにしまっていてもしまうが出来る状態である、修正して」。

## しらべたこと
- 中身の判定（`K.drawer.canPlant` / `inDrawer`）は正しく、同じ材料を2回しまうことはできなかった（ブラウザで押して確認）。
- ただし画面では、しまってある材料にも「しまう」ボタンがそのまま出ていた（うすい色になるだけ）。スマホではおせるように見えるのが問題。

## やったこと
- しまってある材料のカードは「しまう」ボタンと値段を消し、緑の「✓ もうしまってある」札に置きかえた。カードも点線・うすい背景にして区別。
- 赤字の「もうしまってある」は札と重なるので出さない。
- `js/art.js` にチェックの絵（`check`）を追加。
- 版を 0.44 → 0.45 に上げた（`index.html` の `?v=` と `js/screens.js` の `VERSION`）。

## たしかめたこと
- 390x844 / 1280x800 で、えんぴつのこな・のりをしまうと、その2つのボタンが消えて札が出ること、ほかの材料はいつもどおりしまえることを確認。JSエラーなし。
