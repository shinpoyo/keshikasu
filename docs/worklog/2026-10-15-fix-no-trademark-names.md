# 2026-10-15 fix/no-trademark-names — 「かどけし」を商標でない名前に（版0.46）

ユーザー「カドケシは商標だからダメみたい」。

## しらべたこと
- ゲームに出る文字で商標に近いのは「かどけし」の3か所だけ（ゲスト消しゴムの名前・浮かんだときの名前・ニュース1本）。
- 英語と翻訳8言語はもともと「Corner Eraser（角の消しゴム）」系のふつうの言葉なので、翻訳表はそのまま。
- ほかの実在の商品名（MONO・まとまるくん・レーダーなど）はゲーム内に出ていない。「まとまる」はねりけしの説明とひとりごとのふつうの言葉。すなけし・ねりけし・電動消しゴム・ロケット消しゴムは一般名。

## やったこと
- 「かどけし」→「かどかど消しゴム」（`data/guests.js`、`js/guest.js` の「かどかど消しゴム！」、`data/news.js`）。
- コードのコメントにあった商品名も消した（`js/art.js` ほか）。
- 中の名前（`kadokeshi` という id、セーブデータ・★・じっせき）はそのまま。遊んでいたデータは消えない。
- 版を 0.45 → 0.46 に上げた（`index.html` の `?v=` と `js/screens.js` の `VERSION`）。
