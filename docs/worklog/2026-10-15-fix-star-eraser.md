# 2026-10-15 fix/star-eraser — かどかど消しゴムを「ほし形消しゴム」に作りかえ（版0.47）

ユーザー「カドケシは名前（商標）だけでなく、形（意匠登録：10個のキューブをつないだ28個のカド）と特許もコクヨの権利。形もだめか…」。
PR #50 で名前だけ「かどかど消しゴム」にしていたが、絵が白いキューブのジグザグ（カドケシの形）のままだったので、形と名前をまるごと変えた。

## やったこと
- 絵: 白いキューブのジグザグ → 先っぽの丸い、うすむらさきの星形（下に厚み）。机の上の大きい絵とアイコンの両方（`js/art.js` の `starEraser`）。
- こすって出るつぶの色: 白 → うすむらさき（`css/style.css`）。
- 名前: かどかど消しゴム → ほし形消しゴム／Star Eraser。説明「とがった先っぽが5つ。どれでもよく消える。」
- 「28この角」の話をやめた: ニュース1本、じっせき「かどがいっぱい」→「きらきら」。
- 翻訳7言語（es pt fr de tr vi id）も新しい英語に合わせて足し、古い文は消した。`strings.json` も作りなおし。
- 効果（次の28回が10倍、★で強くなる）と中の id `kadokeshi`（セーブ・★・じっせき）はそのまま。
- 版を 0.46 → 0.47 に。
