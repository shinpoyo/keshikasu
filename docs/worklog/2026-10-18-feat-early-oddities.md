# 2026-10-18 feat/early-oddities — 序盤のボケ「ふしぎなできごと」（版0.49）

ユーザーへのアドバイス「序盤にボケと荒唐無稽さが足りない（現実の中のバカバカしさはあるが、突き抜けた変さが弱い）」への対応（修正点リストの1番）。

## やったこと
- **ふしぎなできごと**（`data/incidents.js`・`js/incidents.js`）を8つ追加。つくえに「！」つきの絵が出る → 押すとお話 → 2つのうちどちらかを選ぶ → オチとごほうび（いまの /s の2〜3分ぶん、少なくとも決まった数）。
  1. みどりのカス（60つぶ）… わさびだった
  2. カスあての手紙（400）… 10年後のカスから「もっと こすれ」
  3. カスぜいのお知らせ（3,000）… おつりのほうが多い
  4. カスの母（20,000）… まっさらな消しゴム。計算が合わない
  5. テレビの取材（150,000）… となりのほこりのほうが長くうつる
  6. うちゅうからの使者（2M）… カスを王に。3分で帰ってくる
  7. にせもののカス（30M）… 右はわさびだった
  8. 1つ10億（500M）… 社長のめいしは消しゴムでできていた
- じゅんばんに1つずつ、一度だけ。つぎまで90びょうあける。画面（ずかんなど）を開いているあいだは出ない。消しゴムにもどっても、もう一度は起きない（`state.incidents`）。
- できごとのあとのニュース（`when: { inc: 'wasabi' }` のように、起きたものだけ出る）と、序盤のボケニュース6本を追加。
- じっせき2つ: ひみつ「それはわさび」、「ふしぎな毎日」（全部見た）。
- 翻訳7言語（es pt fr de tr vi id）も追加。
- 版を 0.48 → 0.49 に（PR #52 の上に積んでいる）。
