## 1. どうぐの説明をいつも見せる
- みせの どうぐの行で、名前の下に説明（`buildings.js` の `line`）をいつも出す。まだ買えない「？？？」の行には出さない（ないしょのまま）。
- PC のカーソルの吹き出し・スマホの「くわしく」には同じ説明が重なるので、そちらは数字だけにした。

## 2. 「まぜる」をなくす
前は みせの たたまれた「まぜる」で材料を1回買うと、その色のカスが まるめて出るようになっていた。買うだけの作業で、たたまれていて気づきにくかった。
- みせの「まぜる」を消した。**STAGE が上がると、その STAGE の色のカスが自動で出るようになる**（えんぴつのこな・色えんぴつ = STAGE 2、のり・ほこり = 3、すなけしのこな = 4、金のこな = 5。前に買えるようになった STAGE と同じ）。新しい色が出るようになったら「「黒」のカスが出るようになった！」と知らせる。
- ひきだしは そのまま。材料は「見つけた材料」として `s.mats` に残る（消しゴムにもどっても残る、前と同じ）。まだの材料には「STAGE n になるとしまえる」。
- かけらのお店「えんぴつのこな持ちこみ」「いろんな材料」は「はじめから黒いカスが出る」「はじめから全部の色のカスが出る。ひきだしにも全部しまえる」に言いかえ（中身は同じ）。
- じっせき「まぜてみた」→「色つきデビュー（はじめて色つきのカスが出た）」。id `mix1` はそのまま（もう取った人のセーブがそのまま使える）。
- ずかんの「まぜたもの」の行、チュートリアル3・まるめるページの「みせで材料を買うと…」の文を直した。
- セーブ: 前に買った材料はそのまま。今のセーブで まだ買っていなかった色は、つぎに開いたときに出るようになる（お知らせが出る）。
