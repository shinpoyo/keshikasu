# トップ画面をスマホ一画面に収める（fix/mobile-one-screen、2026-11-06、版0.55）

## 要望
- shinji「トップ画面がスマホ一画面に収まってないわ」

## 原因
- スマホのカス画面は、つくえ（全はばで 380:272）が高さに関係なく同じ大きさだったので、
  画面の高さがひくいと「ミッション」「ほめる・ふく」が下にはみ出してスクロールが必要だった。
  - 360x640 で 61px、375x667 で 45px はみ出し。
  - iPhone の Safari などアドレスバーのあるブラウザでは、見える高さが 660px 前後になるので、ほとんどの機種ではみ出していた。
- 下のタブ（76px）のための あき が 100px あって、少し多かった。

## したこと（css/style.css、スマホ幅 900px 以下だけ）
- つくえを「形をたもったまま ちぢめる」ようにした。高さが足りるときは今までどおり全はば、足りないときだけ小さくなる（いちばん小さくて高さ150px）。
- カス画面の下の あき を タブの高さ + 10px に。
- 高さ 760px 以下のスマホでは、数字と「つぶ・/s」を1行にまとめ、すきまを少しせまく。
- 同じく高さがひくいときは、お知らせ（じっせき かくとく など）を上に出して、ほめる・ふく に かぶせない。はじめの説明が出ているときは今までどおり下。
- 版 0.54 → 0.55（index.html の ?v= と js/screens.js の VERSION）

## 確認したこと
- 360x560・360x640・375x667・390x664・390x844・412x915 で、カス画面がスクロールなしで ほめる・ふく まで入る（scrollHeight = clientHeight）。
- はじめての人（説明が出ている状態）の 360x640 でも入る。
- PC（1366x768、CrazyGames の 1186x668）はスマホ用の指定の外なので変わらない（スクロールなしのまま）。
