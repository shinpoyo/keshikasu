# スマホのみせで「うちゅうの意思」が見えない件を直す（fix/shop-last-tool、2026-11-07、版0.56）

## 要望
- shinji「宇宙の意思画面に表示されなかったよ」

## 解釈
- 「うちゅうの意思」は いちばん最後の どうぐ（data/buildings.js の universe）。
- スマホの「みせ」画面で、いちばん下までスクロールしても うちゅうの意思 の行が 下のタブにかくれて見えない・押せない、と読んだ。
  （つくえ画面・PC のみせ では ちゃんと見えていた）

## 原因
- スマホでは `.pane-shop` 全体をスクロールさせ、中の `.shop-scroll` は `overflow: visible; padding-bottom: 100px`（下のタブのぶん）にしていた。
- ところが `.shop-scroll` は PC 用の `flex: 1; min-height: 0` のままで、高さが画面ぶん（620px など）に止められていた。
  中身はそこからはみ出して見えるだけなので、下の 100px の あき が 中身の後ろに来ず、最後の行が 画面のいちばん下＝タブ（約76px）の下にかくれていた。
- 最後の どうぐ は いつも かくれていたが、うちゅうの意思 が出るまでは「かげ（？？？）」が最後だったので気づきにくかった。

## したこと
- css/style.css（スマホ幅 900px 以下）: `.pane-shop .shop-scroll` に `flex: none` を足して、中身の高さ＋100px の あき になるようにした。
- 版 0.55 → 0.56（index.html の ?v= と js/screens.js の VERSION）

## 確認したこと（Playwright、どうぐ全部5こ・うちゅうの意思3こ のセーブ）
- 390x844: 直す前は うちゅうの意思 の行が 768〜844px（タブの下）。直した後は 668〜744px でタブの上に全部見える。
- 360x640 でも タブの上に全部見える。
- PC（1366x768）は もともと見えていて、変わらない。
- つくえ画面の うちゅうの意思 は もともと見えている。
