# スマホでお知らせがタイトルに重なって見切れる件を直す（fix/toast-over-title、2026-11-09、版0.57）

## 要望
- shinji「見切れてるやんーーー」（スマホのみせ画面のスクリーンショット）

## 見えていたこと
- 上の「キラキラタイム！ /s が 7倍」の黒い帯が、左のタイトル「けしカス」に重なって「けし」までしか見えない。
- 一番下の「うちゅうの意思」が下のタブにかかっていたのは、スクロールの途中だったため。いちばん下までスクロールするとタブの上に全部出る（PR #59 の直しはきいている）。

## 原因
- この帯はお知らせ（トースト）。PR #58 で、高さ 760px 以下のスマホではお知らせを画面の上（上から 8px）に出すようにした。
  そこはタイトルとずかんボタンの行なので、出ている間（約3秒）タイトルが隠れていた。
  アドレスバーや下のボタンがあるスマホだと、見える高さが 680px くらいになるので、この配置になる。

## したこと
- css/style.css（高さ 760px 以下のスマホ）: お知らせの位置を上から 48px（ニュースの行）にした。タイトルの行には重ならず、ニュースが数秒隠れるだけ。
  お知らせの高さもニュースの行（30px）にそろえた。
- 高さが十分あるスマホ（下のタブの上に出る）と PC は変えていない。
- 版 0.56 → 0.57（index.html の ?v= と js/screens.js の VERSION）

## 確認したこと（Playwright）
- 412x680（スクリーンショットと同じくらい）・390x664・375x667・360x560: お知らせは 48〜78px でニュースの行と同じ位置、タイトル（〜37px）に重ならない。
- 長いお知らせ（ミッション達成、2行）でもタイトルは見える。
- 412x915: もとどおり下のタブの上に出る。
- みせでどうぐ全部持ち: いちばん下までスクロールすると、うちゅうの意思はタブの上に全部見える（412x680・360x560・412x915）。
- 前後の比べ: project-files の keshikasu/toast-title-before-after.png

## 追加（2026-11-11）: スマホに古い版が残って、下までスクロールできなかった件
- shinji「下にスクロール出来なかったからいってんだ」。遊んでいた場所は shinpoyo.github.io のページ。
- 送ってもらった画面は 版0.55（PR #59 の前）と同じ見え方。Pages には 11/7 に 0.56 が出ていて、
  いまの版では指でのスクロールで最後（うちゅうの意思）まで行けることを Playwright のタッチ操作で確かめた（0.55 では最後がタブの下）。
- スマホのブラウザが、開いたままのタブを古い版のまま残していたと考えられる。
- js/main.js に `watchUpdate()` を足した: 起動したときと、タブに戻ってきたとき（1分に1回まで）に
  サーバーの index.html を no-store で読み、`style.css?v=` が今の版と違えばセーブして読みなおす。
  同じ版への読みなおしは1回だけ（sessionStorage）。CrazyGames（K.ads.wanted）と file:// ではしない。
- 確認: index.html の版を 0.99 に書きかえてタブに戻る操作をすると、読みなおしてカスの数も残る。版が同じなら読みなおさない。
