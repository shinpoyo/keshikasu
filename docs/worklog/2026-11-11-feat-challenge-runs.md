# 終盤の「やることがない」と、こする倍率の強すぎを直す（feat/challenge-runs、2026-11-11、版0.58）

## 要望
- shinji「もうやることない。こする20倍と777倍出たら勝ち確定。どうする？」（消しゴムにもどる画面: かけら +51694、+51730% /s）

## 原因
- **こする倍率が かけ算で重なっていた**: ゴールデンの「ごりごりタイム」777倍 × ひきだしの「ざらざらタイム」20倍 × 広告2倍 ＝ 約3万倍。
  こする1回に /s の 3〜8% が入るので、13秒のごりごりタイムで /s の 約45時間分が入る。これで何でも買えて勝負が決まっていた。
- **かけらの使い道がない**: かけらのお店は全部買っても 約1,600 こ。5万こ以上あると全部買えてしまい、/s +1%/こ が増えるだけ。
  周回がすぐ終わり、次の目標がなかった。

## 案（スレッドで提案）
1. **ちょうせん（しばりのある周）** ← おすすめ・今回実装
2. かけらで買える「終わりのない」強化（使うほど値段が上がる）
3. 新しい STAGE 8 以降とどうぐの追加（絵が多く必要）

## したこと
- js/shop.js clickPower: 777倍と20倍は重ならず、大きいほうだけ（広告2倍はそのまま）。
- js/challenge.js（新規）: ちょうせん3つ。消しゴムにもどるときに選び、その周で STAGE 7 まで育てたらクリア。
  - かけらを忘れる: かけらの /s が効かない
  - どうぐは3種類: ＋どうぐは3種類まで（はじめからのアリさん・指はもらえない）
  - しずかなつくえ: ＋こすってもつぶが出ない・ゲスト消しゴムが来ない
  - クリアごとに ずっと /s 2倍（3つで8倍）。いちばん速いタイムを記録（何回でもタイムをねらえる）。
- js/screens.js: 消しゴムにもどる画面に「ちょうせんする？」の選択、メニューに「ちょうせん」（今の STAGE・やめるボタン・記録）。
- js/ui.js: 3種類そろった後の どうぐは「どうぐは3種類まで」と赤で出して押せない。
- セーブに challenge { on, start, cleared, best }。消しゴムにもどっても残る。
- ことば: ja/en と 7言語のほんやく（tools/i18n/*.json → build-i18n.py）。
