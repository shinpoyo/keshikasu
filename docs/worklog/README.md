# 作業履歴（1作業1ファイル）

いくつもの作業（ブランチ・PR）を同時に進めても作業履歴でコンフリクトしないように、
2026-10-01 から **作業ごとに1つのファイル** を作る。

- 置き場所: `docs/worklog/`
- ファイル名: `YYYY-MM-DD-ブランチ名.md`（例: `2026-10-01-feat-roll-shadows.md`。`/` は `-` にする）
- 中身: 見出し1つ（何をしたか・ブランチ・日付）と、ユーザーの要望・したこと・確認したこと
- 同じブランチで続けて直したときは、そのブランチのファイルに書き足す
- ほかのファイル（このファイルや `docs/worklog.md`）には書き足さない。一覧はファイル名の日付順で見る

2026-09-30 までの履歴は [../worklog.md](../worklog.md) にまとめてある（もう書き足さない）。
